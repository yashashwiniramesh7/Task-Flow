# TaskFlow – Productivity and Task Management Website

## About the Project

TaskFlow is a web development project created as part of my **Web Technology subject**. It is designed to help users organize their daily tasks, manage deadlines, and track their productivity through a simple and interactive website.

This project helped me understand how HTML, CSS, Bootstrap, and JavaScript work together to build a website.

## Project Objectives

- To create a user-friendly task management website.
- To organize tasks based on priority and deadlines.
- To track completed and pending tasks.
- To display task statistics using charts.
- To learn practical web development concepts.

## Features

- **Home Page:** Introduces TaskFlow and displays its main features.
- **Task Dashboard:** Add, edit, delete, search, and manage tasks.
- **Task Priority:** Organize tasks into High, Medium, and Low priority.
- **Progress Tracking:** View the percentage of completed tasks.
- **Analytics:** View total tasks, completed tasks, pending tasks, success rate, and charts.
- **Calendar:** View dates and identify days with scheduled tasks.
- **Upcoming Deadlines:** View tasks with their due dates.
- **About Page:** Displays the project overview, mission, vision, and technologies used.
- **Contact and Settings:** Includes a contact form, dark/light theme option, and notification preferences.
- **Animations:** Includes visual effects and animations to improve the user experience.

## Technologies Used

- **HTML5:** Creates the structure of the website.
- **CSS3:** Styles the website with colors, layouts, and effects.
- **Bootstrap 5:** Helps create a responsive layout and navigation menu.
- **JavaScript:** Adds interactivity and handles task operations.
- **Font Awesome:** Provides icons for different sections.
- **Chart.js:** Displays task analytics through charts.
- **GSAP:** Adds animations to website elements.
- **AOS:** Adds animations when elements appear on the page.
- **Local Storage:** Stores tasks and user preferences in the browser.

## How to Run the Project

1. Download or clone this repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Make sure the `css` and `js` folders contain their respective files.
4. Open `index.html` in a web browser.
5. Navigate through the website using the navigation menu.

**Note:** An internet connection is required for the external libraries, fonts, icons, and animation resources loaded through online CDNs.

## How It Works

1. Users open the TaskFlow home page.
2. They go to the Dashboard and create tasks with a name, priority, and due date.
3. Tasks can be marked as completed, edited, deleted, searched, or filtered by priority.
4. The website saves task information in browser Local Storage.
5. The Analytics page displays task statistics and charts based on saved tasks.
6. The Calendar page highlights dates containing tasks and lists upcoming deadlines.
7. The Contact and Settings page allows users to change preferences.
